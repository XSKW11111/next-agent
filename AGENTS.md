# Agent instructions

## Coding style

[CODING_STYLE.md](CODING_STYLE.md) is the coding style for this repository. Read it before planning, implementing, reviewing, or testing a code change, and follow it.

- A **Must** rule is required. If it cannot be followed, document the exception, its risk, and how it was verified.
- A **Should** rule is the default. Deviate only when the alternative is clearer or safer, and say why.
- A project-specific rule may tighten this guide. It may override a **Should** rule when the reason is documented. It must not silently override a **Must** rule.

Domain language for this support agent is in [GLOSSARY.md](GLOSSARY.md). The current design is in [next-agent-system-architecture.md](next-agent-system-architecture.md).
